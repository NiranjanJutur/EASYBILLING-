# ShopLedger roadmap

This roadmap is a guide for open-source contributors, not a promise of release dates. Ideas are grouped by the value they bring to small businesses.

## Next improvements

- [ ] Add configurable invoice templates, store logos, and receipt-paper layouts.
- [ ] Add backup and restore for local business data.
- [ ] Improve barcode-scanner compatibility across more Android devices.
- [ ] Improve camera capture and item-recognition feedback.
- [ ] Add more keyboard shortcuts and accessibility labels for web and Android.
- [ ] Add translations and configurable Indian-language invoice text.
- [ ] Add CSV import/export for products, customers, and bills.

## Reporting and operations

- [ ] Add date-range and product-level sales exports.
- [ ] Improve purchase, supplier, and stock-movement reports.
- [ ] Add configurable low-stock notifications.
- [ ] Add optional backup/sync status and recovery guidance.

## Community requests

Use GitHub Issues to propose a feature. Describe the business workflow, an example invoice or screen layout using fake data, and how the result should work offline.
